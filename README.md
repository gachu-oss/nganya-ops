# NganyaOps — Matatu Fleet Operations Manager

NganyaOps is a lightweight web application built for matatu fleet operators and SACCO managers to track daily collections, Cash vs. M-Pesa splits, crew assignments, NTSA/insurance compliance, garage maintenance, and per-vehicle profitability.

## Live Demo
- **Deployed on Vercel:** [https://nganya-ops.vercel.app/](https://nganya-ops.vercel.app/)

## Tech Stack
- **Frontend:** React (Vite) + React Router + Tailwind CSS
- **Backend & Auth:** Supabase (PostgreSQL + Email/Password & Google OAuth)
- **Testing & CI:** Vitest + React Testing Library + GitHub Actions

## Features
- **Operational Dashboard:** Real-time summary cards for active/garage vehicles, gross revenue, total expenses, net profit, NTSA/insurance renewal alerts, and a per-matatu profitability ranking table.
- **Fleet Management:** Register matatus with plate number, nickname, manufacturer/model, 14/33-seater capacity, route, daily target, and insurance/NTSA expiry dates; toggle status (`Active` / `Garage`); search and filter vehicles; and monitor today's target achievement badge (`Target Hit` vs. `Shortfall`).
- **Crew Roster:** Register drivers and conductors and assign them to specific matatus.
- **Daily Trip & Revenue Logs:** Record daily trips, auto-fill assigned shift crew, split collections between Cash and M-Pesa Till/PoChi, log fuel/crew/stage expenses, monitor split mismatches, and filter logs by vehicle or date.
- **Maintenance & Garage Log:** Track repair bills, toggle repair status (`Pending` / `Completed`), and monitor total garage spend.

## Local Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/gachu-oss/nganya-ops.git
   cd nganya-ops/nganyaops
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure environment variables**
   Create a `.env.local` file inside `nganyaops/` with your Supabase project credentials:
   ```env
   VITE_SUPABASE_URL=your_supabase_project_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

## Deployment (Vercel)
- Set the Vercel **Root Directory** to `nganyaops`.
- Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in Vercel **Project Settings → Environment Variables**.
- [vercel.json](nganyaops/vercel.json) rewrites client-side routes to `/index.html` so direct links and OAuth redirects work on refresh.
- In Supabase **Authentication → URL Configuration**, add your Vercel URL (`https://nganya-ops.vercel.app/**`) and `http://localhost:3000/**` to **Redirect URLs**.

## Supabase Database Schema

Run the following SQL in your Supabase SQL Editor to set up the required tables:

```sql
create table if not exists vehicles (
  id bigint generated by default as identity primary key,
  plate_number text not null unique,
  nickname text default '-',
  manufacturer text default '-',
  seat_count integer not null default 14,
  route text not null,
  daily_target numeric not null default 0,
  insurance_expiry date,
  ntsa_inspection_expiry date,
  status text not null default 'Active',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

create table if not exists crew (
  id bigint generated by default as identity primary key,
  full_name text not null,
  role text not null,
  phone text not null,
  assigned_plate text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

create table if not exists trip_logs (
  id bigint generated by default as identity primary key,
  plate_number text not null,
  driver_name text,
  conductor_name text,
  trip_date date not null default current_date,
  trips_count integer not null default 1,
  gross_revenue numeric not null default 0,
  cash_collected numeric not null default 0,
  mpesa_collected numeric not null default 0,
  fuel_cost numeric not null default 0,
  crew_allowance numeric not null default 0,
  other_expenses numeric not null default 0,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

create table if not exists maintenance_logs (
  id bigint generated by default as identity primary key,
  plate_number text not null,
  service_date date not null default current_date,
  description text not null,
  cost numeric not null default 0,
  status text not null default 'Pending',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```
