# NganyaOps — Matatu Fleet Operations Manager

NganyaOps is a lightweight web application built for matatu fleet operators and SACCO managers to track daily collections, shift expenses, crew assignments, garage maintenance, and per-vehicle profitability.

## Tech Stack
- **Frontend:** React (Vite) + Tailwind CSS
- **Backend & Auth:** Supabase (PostgreSQL + Email/Password Authentication)

## Features
- **Operational Dashboard:** Real-time summary cards for active/garage vehicles, gross revenue, total expenses, net profit, and a per-matatu profitability ranking table.
- **Fleet Management:** Register matatus with plate number, nickname, route, and daily target; toggle status (`Active` / `Garage`); search and filter vehicles; and monitor today's target achievement badge (`Target Hit` vs. `Shortfall`).
- **Crew Roster:** Register drivers and conductors and assign them to specific matatus.
- **Daily Trip & Revenue Logs:** Record daily trips, gross collections, fuel costs, crew allowances, and stage expenses with automatic net profit calculation and date/vehicle filtering.
- **Maintenance & Garage Log:** Track repair bills, toggle repair status (`Pending` / `Completed`), and monitor total garage spend.

## Local Setup

1. **Clone the repository**
   git clone https://github.com/gachu-oss/nyanya-ops.git
   cd nyanya-ops/nganyaops

2. **Install dependencies**
   npm install

3. **Configure environment variables**
   Create a `.env` file inside `nganyaops/` with your Supabase project credentials:
   VITE_SUPABASE_URL=your_supabase_project_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

4. **Start the development server**
   npm run dev

## Supabase Database Schema

Run the following SQL in your Supabase SQL Editor to set up the required tables:

create table if not exists vehicles (
  id bigint generated by default as identity primary key,
  plate_number text not null unique,
  nickname text default '-',
  route text not null,
  daily_target numeric not null default 0,
  status text not null default 'Active',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

create table if not exists crew (
  id bigint generated by default as identity primary key,
  full_name text not null,
  role text not null,
  phone text not null,
  assigned_plate text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

create table if not exists trip_logs (
  id bigint generated by default as identity primary key,
  plate_number text not null,
  trip_date date not null default current_date,
  trips_count integer not null default 1,
  gross_revenue numeric not null default 0,
  fuel_cost numeric not null default 0,
  crew_allowance numeric not null default 0,
  other_expenses numeric not null default 0,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

create table if not exists maintenance_logs (
  id bigint generated by default as identity primary key,
  plate_number text not null,
  service_date date not null default current_date,
  description text not null,
  cost numeric not null default 0,
  status text not null default 'Pending',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
